# Lab-6-Polynomial-Approximation
To obtain the linear and polynomial approximation (curve fitting) for a given data set.

This project involves a laboratory experiment where I examined how to illustrate real-world data through curve fitting methods. The primary objective was to learn how to identify a function that accurately represents a specific collection of data points rather than merely graphing them. In this experiment, I engaged in manual calculations as well as MATLAB implementation to explore the relationship between theory and practical applications

A significant observation was that the equation acquired from MATLAB initially appeared different from the one derived by hand. Nevertheless, upon examination and simplification, both were determined to be quite similar. This validated that the computational technique was dependable and aligned with the theoretical framework.

In general, this experiment assisted me in progressing beyond merely using formulas. I acquired skills in data analysis, selecting appropriate models, and validating outcomes through both manual and computational techniques. It provided me with a better grasp of how curve fitting is applied in practical situations and emphasized the significance of choosing the right model for precise data representation
